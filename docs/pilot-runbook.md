## Training task sequence on each PC

Use disposable copies. Compare scalar measurements within the recorded tolerance (no more than 0.1% for validation), money rounded consistently to the displayed precision, and exact saved geometry/rates where raw artifacts permit.

| Task | Independent expected result | Capture for each PC |
|---|---|---|
| Guide/open/calibrate | Guide/examples/images accessible offline; calibrate full bold training side as 10 m and verify another known dimension | Guide revision, estimator steps/friction, scale and screenshot |
| Fresh five-tool takeoff | Named Grid length 10 m; Grid area 100 m²; Grid perimeter 40 m; Grid wall 10 m × 3 m = 30 m²; Grid count 1 ea | Expected/actual each, geometry/project hash, tester/date |
| Correct geometry | Deliberately move a disposable vertex, correct to known landmark; Enter/Escape/undo; Snap F3/Alt and arc edge/toggle where applicable | Before/after expected/actual, source fixture/oracle; do not assume grid checks every arc |
| Name/order/pan/zoom | Review groups, change ordering/name on disposable data; inspect landmark registration and persisted order after reopen | Before/after and reopened artifacts; numeric/visual evidence |
| Library and manual prices | Six-column training library, invalid file preserves prior data; preview/explicit replace; matching-unit Apply Rates; manual override then later import leaves project snapshot unchanged | Library revisions/hashes, independent prices, all same-name/type affected rows, restoration evidence |
| Units | Matching basis required for library; quantity/reciprocal rates change while reviewed money stays constant | Before/after units, quantities/rates/money and independent conversion |
| Save/reopen/project-only transfer | Save a distinct copy and reopen; copy only .clmc between the two actual PCs without source PDF/library; embedded PDF/scales/geometry/prices/order preserved | Source/target identifiers, actual absent dependencies, file hashes and expected/actual |
| Backup/recovery | One adjacent last-good backup; detached save-copy; completed approximately 60-second capture; explicit recover/keep/discard; failed save leaves work unsaved | Reuse exact-scope Phase 20 evidence or collect safely with disposable session, original/backup hashes and timestamps |
| Internal XLSX and CSV | Six-row comparison with optional unpriced Retest area: cost 740, selling 962, margin 222 | Both actual exports/hashes/readback and Estimate/project; UTF-8/comma interpretation |
| Ordinary representative job | Independent actual construction-plan quantities/prices and predeclared acceptable performance | Permitted fixture and oracle hashes, pages, timings/response/memory observations, errors, exports and estimator assessment |

The six-row example is **synthetic practice**, distinct from the ordinary-job oracle. Expected line costs/selling: Linear 150/195, Area 300/390, Retest area 0/0, Perimeter 40/52, Wall 150/195, Count 100/130. Material/labor rates and 30% markup are in the guide. Five tool types do not alone cover every representative plan, mixed-page calibration, curved edge or legacy case.
